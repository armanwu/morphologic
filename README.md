# MORPHOLOGIC

**A Blender Python-based computational design tool for exploring architectural massing through morphological rules, geometric transformations, and generative design.**

## Overview

MORPHOLOGIC is an experimental computational design tool developed with Blender and Python. It explores architectural form through procedural mass generation and rule-based geometric transformations.

The system generates multiple architectural massing variations through controlled randomness and morphological operations.

## Features

- Procedural architectural mass generation
- Addition and stacking of secondary masses
- Subtraction and spatial void formation
- Rotation, tapering, and twist transformations
- Adjustable geometric parameters
- Controlled randomness using seed-based generation
- Reproducible design variations
- Cycles rendering and material visualization

## Requirements

- Blender 5.2.1 LTS
- Python (Blender built-in Python environment)

## Usage

1. Open Blender.
2. Navigate to the Scripting workspace.
3. Load the MORPHOLOGIC Python script.
4. Run the script.
5. Open the 3D Viewport sidebar by pressing `N`.
6. Select the Morphologic panel.
7. Adjust parameters and morphological rules.
8. Generate new compositions or reproduce previous results using the seed.

## Research Context

MORPHOLOGIC explores the relationship between computational logic, geometric transformation, and architectural composition. It is intended as an experimental platform for architectural design exploration and research through design.
